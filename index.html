Инструкция по установке

Приложения пока нет в Play Market — ставится файлом (APK), это безопасно, нужно один раз разрешить установку.

01 Нажмите «Скачать для Android» выше. Файл начнёт загружаться через браузер.
02 Если Chrome покажет предупреждение «Файл может быть опасен» — это стандартно для файлов не из Play Market. Нажмите «Скачать всё равно».
03 Откройте скачанный файл. Android покажет экран «неизвестные источники».
Так выглядит этот экран (текст может быть на русском)
04 Нажмите «Настройки» в предупреждении → включите «Разрешить из этого источника» → вернитесь назад.
05 Нажмите «Установить» — и запустите ONePay.
