Как установить на Android

Приложения пока нет в Play Market, поэтому устанавливается файлом (APK) — это безопасно, нужно только один раз разрешить установку.

  1. Нажмите «Скачать для Android» выше. Файл начнёт загружаться через браузер.
  2. Если Chrome покажет предупреждение «Файл может быть опасен» или «Этот тип файлов может нанести вред устройству» — это стандартное предупреждение для любых файлов не из Play Market, а не признак проблемы с самим приложением. Нажмите «Скачать всё равно» (или «Подробнее» → «Скачать»).
  3. Откройте скачанный файл (через уведомление о загрузке или в «Файлах»). Android покажет: «Для вашей безопасности телефон не может установить неизвестные приложения из этого источника».
    Так выглядит этот экран (текст на вашем телефоне может быть на русском)
  4. Нажмите «Настройки» в этом предупреждении → включите переключатель «Разрешить из этого источника» → вернитесь назад.
  5. Нажмите «Установить» — и запустите ONePay.
